## Одоогоор амлаж болохгүй зүйл

- Бодит хэрэглэгчийн төхөөрөмж дээр хэмжээгүй FPS.
- Туршаагүй browser, iOS fullscreen/audio ажиллагаа.
- Procedural гариг NASA зурагтай ижил фото-бодит харагдана гэх амлалт.
- File дээр давхар товшиход бүх browser-д бүрэн 3D ажиллана гэх амлалт.
- Hyperdrive, гариг хооронд хэдхэн минутын бодит нислэг.
- CSS дангаараа 3D mesh renderer, audio engine, бүрэн interactive flight controller болсон гэх тайлбар.
- Код бичигдээгүй байхад demo бүрэн болсон гэх мэдэгдэл.

## Техникийн эх сурвалж

Доорх эх сурвалжийг 2026-11-12-нд баримтын техникийн сонголтыг шалгахад ашиглав. Эдгээрийг нээхэд интернэт шаардлагатай боловч ирээдүйн demo ажиллахад энэ холбоосууд шаардагдахгүй.

1. **Three.js r187:** тодорхой release байгаа эсэхийг шалгав. [Албан ёсны release](https://github.com/mrdoob/three.js/releases/tag/r187)
2. **Three.js package:** `version: 0.187.0`, ES module бүтэц, MIT лицензийн мэдээллийг шалгав. [r187 package.json](https://raw.githubusercontent.com/mrdoob/three.js/r187/package.json)
3. **WebGLRenderer:** WebGL 2 ашигладаг, WebGL 1 r163-аас дэмжигдэхгүй гэдгийг шалгав. [Албан ёсны renderer docs](https://threejs.org/docs/pages/WebGLRenderer.html)
4. **Three.js installation:** локал development server/module ачаалалтын чиглэлийг лавлав. [Installation](https://threejs.org/manual/pages/installation.html)
5. **Web Audio:** аудиог хэрэглэгчийн үйлдлээр эхлүүлэх browser бодлогын тайлбар. [MDN best practices](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)
6. **Autoplay:** медиа болон Web Audio autoplay хязгаарын тайлбар. [MDN autoplay guide](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)
7. **Reduced motion:** системийн хөдөлгөөн багасгах хүсэлтийг илрүүлэх CSS media feature. [MDN prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)

## Одон орны агуулгын эх сурвалж

Энэ төслийн агуулга нь доорх баримтуудыг богино, сурагчдад ойлгомжтой байдлаар хэрэглэнэ. Дэлгэцийн хэмжээ, камерын ойртолт, аяллын хугацаа, гаригийн гадаргуугийн procedural detail-ийг эдгээр эх сурвалж баталж байгаа гэж үзэхгүй.

- **Дэлхий:** гаригийн бүтэц, далай, агаар мандлын суурь лавлах. [NASA Earth facts](https://science.nasa.gov/earth/facts/)
- **Нарны нуман prominence:** Нарны гадаргуугаас гадагш сунасан тод бүтэц. [NASA — Solar prominence](https://www.nasa.gov/image-article/what-solar-prominence/)
- **Астероидын бүс:** кинонд дүрсэлдэг шиг шахцалдсан чулуулгийн талбай биш гэдгийг тайлбарлахад ашиглав. [NASA Dawn FAQ](https://science.nasa.gov/mission/dawn/faq/)
- **Бархасбадийн Их улаан толбо:** аварга шуурга гэдгийг лавлав; хэмжээ нь өөрчлөгддөг тул энэ баримтад яг тоон харьцаа өгөөгүй. [NASA Hubble — Great Red Spot](https://science.nasa.gov/asset/hubble/the-great-red-spot-an-ancient-storm-in-jupiters-atmosphere/)
- **Санчирын цагираг:** гол цагирагууд ихэвчлэн мөсөн хэсгүүдээс бүрддэг тухай лавлах. [NASA Cassini — Rings](https://science.nasa.gov/mission/cassini/science/rings/)

## Шинээр нэмсэн үзэгдлүүдийн баримтын лавлах

- **Энцелад:** өмнөд туйл орчимд мөсөн ширхэг ба усны уурын plume оргилдог. [NASA Cassini — Enceladus](https://science.nasa.gov/mission/cassini/science/enceladus/)
- **Voyager:** од хоорондын орчны судалгаа, гелиосферийн хил давсан тухай лавлах. Аппараттай уулзах зам нь манай уран сайхны зохиол. [NASA Voyager — Interstellar mission](https://science.nasa.gov/mission/voyager/interstellar-mission/)
- **Хязгаарын ялгаа:** гелиопауз нь гелиосферийн зах; нарны аймгийн алсын биетүүдийн бүс түүнээс цааш сунана. [NASA Voyager FAQ](https://science.nasa.gov/mission/voyager/frequently-asked-questions/), [NASA Oort Cloud facts](https://science.nasa.gov/solar-system/oort-cloud/facts/)

Voyager-ийн хэсгийг уран сайхны, хугацаа шахсан алсын нислэг гэж дүрслэнэ. Гелиопаузыг гэрэлт хатуу хана болгон харуулахгүй; Voyager өнгөрлөө гээд нарны аймгаас бүрэн гарсан гэж хэлэхгүй. V2-д цааш үсрэх найруулга орно.

## Хэрэгжүүлэлт эхлэхээс өмнө хянах дөрвөн зүйл

1. V1-ийн найман бүлэг, санал болгосон 5:40 хугацаа, Нарны flyby, Санчир–Энцеладын оргил, Voyager-ийн төгсгөлийн нарийн кадр.
2. Уран сайхны procedural texture-ийн чиглэл эсвэл бодит фото texture шаардлагатай эсэх.
3. Үндсэн үзүүлэх компьютер, проекторын хэмжээ, бодит GPU, browser.
4. Нэмэлт narrator хэрэгтэй эсэх; санал болгосон суурь хувилбар narrator-гүй.

Энэ жагсаалт нь одоогийн баримт бичгийг дуусгахад саад болох заавал хариулах асуулт биш. Хэрэгжүүлэлт рүү орохын өмнөх хяналтын цэгүүд юм.
