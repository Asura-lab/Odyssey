# 07. Хөгжүүлэлтийн roadmap

## Одоогийн зөвшөөрөгдсөн ажил

**Одоогийн ажил — баримт бичиг ба репозиторийн суурь.** Хэрэглэгчийн хүсэлтээр [Asura-lab/Odyssey](https://github.com/Asura-lab/Odyssey)-г холбож, 11 баримтыг `docs/` дотор байрлуулна. Root README, Git/редакторын тохиргоо, ажлын зарчим, ирээдүйн эх код ба материалын хоосон хавтаснуудтай эхний commit хийнэ. Бүрэн demo, dependency, model, shader, runtime хэрэгжүүлэлт ба deployment энэ алхамд орохгүй. P1 болон дараах бодит хөгжүүлэлт тусдаа дараагийн ажил.

Доорх дараалал нь хэрэгжүүлэлт эхлэхэд баримтлах төлөвлөгөө. Хугацаа нь ажлын хэмжээний баримжаа; одоо баталгаажуулсан delivery амлалт биш. «Ажлын өдөр» нь нэг хүн төвлөрч ажиллах ойролцоо хэмжүүр.

## Бүтээгдэхүүний хувилбарын roadmap

| Хувилбар | Үзэгдлийн хүрээ | Хүргэх зарчим |
|---|---|---|
| V1 | Дэлхийн sunrise, Нарны flyby, хурдасгал, астероид, Бархасбадь, Санчир, Энцелад, Voyager/алсын бүс | Эхлээд үүнийг бүрэн, чанартай demo болгоно |
| V2 | Нарны аймгаас цааш шилжилт, ойрын одны систем, аварга улаан од | V1-ийн ижил хөлөг, үндсэн аяллыг үргэлжлүүлнэ |
| V3 | Оддын мананцар | Өнгө, үүл, гүний шинэ хэсэг |
| V4 | Хар нүх, нийт аяллын эцсийн найруулга | Тусдаа renderer/shader туршилттай оргил |

V1 нарны аймагт хязгаарлагдана гэдэг нь баталсан хүрээ. Дараагийн үзэгдлүүдийг V2–V4-д ийн багцлах нь төлөвлөлтийн санал; эдгээрийг V1-ийн шалгуурт оруулахгүй. Дэлхийдээ буцах хэсгийг V1-д хийхгүй, нийт аяллын хожмын төгсгөлд дахин шийдэж болно. Сүүлт од, Сарны тусдаа бүлэг одоогийн V1-ийн зайлшгүй ажил биш.

## V1-ийг хэрэгжүүлэх ажлын үе шатууд

P0–P7 нь нэг V1 хувилбарыг хийх ажлын шат. V1–V4 нь бүтээгдэхүүний агуулгын хувилбар. Энэ хоёр дугаарлалт өөр утгатай.

| Шат | Ажил | Гаралт | Баримжаа |
|---|---|---|---|
| P0 | Үзэл баримтлал, зохиол, шаардлага, технологи | Энэ баримт бичгийн багц | Одоогийн ажил |
| P1 | Техникийн суурь ба хамгийн эрсдэлтэй кадрын proof | Нэг master clock, нэг гариг, цагирагийн occlusion, fallback | 0.5–1.5 өдөр |
| P2 | Cockpit ба гол UI | Нэг хөлгийн тогтвортой бүхээг, keyboard/touch | 1–2 өдөр |
| P3 | Бүх аяллын rough cut | Эхлэлээс төгсгөл хүртэл 5:40 дараалал | 1–2 өдөр |
| P4 | V1-ийн онцлох кадрууд | Sunrise, Sun flyby, asteroid, storm, ring, Enceladus, Voyager | 2–4 өдөр |
| P5 | CSS эффект ба аудионы уялдаа | Warp, glow, reflection, transition, sound cues | 1–2 өдөр |
| P6 | Responsive, accessibility, performance | Desktop/mobile, reduced motion, fallback | 1–2 өдөр |
| P7 | Ангийн rehearsal, QA, багц | Offline багц, тайлан, багшийн тайлбар | 0.5–1 өдөр |

Хэрэгжүүлэлтийн нийт баримжаа **7–14.5 ажлын өдөр**. Сонгосон төхөөрөмж, шаардсан фото-бодит байдал, харагдах байдлын засвараас хамаарна. Энэ хэмжээнд үүнийг жижиг landing page шиг тооцохгүй.

## P0 — Баримт бичиг

**Хийх зүйл:**

- Нэг аяллын зорилго, хэрэглэгчийн хязгаарыг тогтоох.
- V1-ийн 5:40 зохиол, найман бүлэг, 13 гол кадр, орчны дууны төлөвлөгөө.
- Технологи бүрийн үүрэг, offline шаардлага, fallback тодорхойлох.
- UI урсгал, 3D/texture бүртгэл, гүйцэтгэлийн төсөв.
- Хөгжүүлэлтийн дараалал, чанарын шалгуур, багшийн дараалал.

**Гарах нөхцөл:** бүх баримт нэг ижил бүлэг, хугацаа, технологи, хязгаартай; Desktop хавтаст зөвхөн баримт байна.

## P1 — Техникийн эрсдэлийг эхэлж шалгах

P1 эхлэхэд эхлээд pause, seek, tab visibility, төгсгөлийн state-ийн meaningful test бичнэ. Дараа нь минимал controller үүсгэнэ. Графикийн тестийг shader-ийн дотоод мөр бүрийг дуурайлгахын оронд бодит browser кадраар шалгана.

**Технологийн сонголт:** native JavaScript, Three.js, GSAP, framework, shader, бэлэн model/texture, аудио зэрэг шаардлагатай хэрэгслүүдийг энэ шатанд чанар, гүйцэтгэлээр сонгоно. Өмнөх хүснэгтийн нэрсийг заавал ашиглах жагсаалт гэж үзэхгүй. HTML/CSS нь үндсэн бүтэц, зохиомж, cockpit, гол харагдах эффектүүдийн тулгуур хэвээр байгааг хамт шалгана.

**Яагаад Санчирыг эрт шалгах вэ?** Цагирагийн урд/арын далдлалт, тунгалаг material, camera flyby нь бүтээлийн оргилыг шийдэх эрсдэл. Бүх UI-г өнгөлсний дараа энэ кадр боломжгүй болохыг мэдэж болохгүй.

**Гаралт:**

- Сонгосон нэмэлт сангуудын хувилбарыг тогтоож, локал ачаалалтыг шалгана.
- Нэг гариг, цагираг, camera test; texture ба depth зөв.
- Нарны glow/bloom бичвэрийг арилгахгүй, Энцеладын plume particle төсөвт багтдаг эсэхийг богино техникийн туршилтаар шалгана.
- Master clock-оос pause/seek хийж болно.
- WebGL ажиллахгүй үед CSS кадр харагдана.
- Локал HTTP offline орчинд ажилладаг нь бодитоор шалгагдана.

**Гарах нөхцөл:** камер цагирагаар буруу зүсэж орохгүй, гаригийн арын цагираг нэвт харагдахгүй, fallback хар дэлгэцгүй. FPS-ийг үндсэн үзүүлэх төхөөрөмж дээр анх хэмжинэ.

## P2 — Хөлгийг нэг орон зай болгох

Cockpit CSS, өнгө, typography, үндсэн товч, focus, touch target, жижиг telemetry, progress зэргийг хийнэ. Гадна хөлгийн mesh-ийг cockpit-ийн хэлбэртэй уялдуулна.

**Гарах нөхцөл:** компьютер болон утасны wireframe-д бүх гол үйлдэл ашиглагдана; зайлшгүй текст уншигдана; HTML нь график ачаалаагүй ч бүтэцтэй байна. Технологи салгаж харуулах UI байхгүй.

## P3 — Бүтэн rough cut

V1-ийн найман бүлгийг эхний энгийн detail-тай ч нэгэн бүтэн хугацаанд холбоно. Хуудас солихгүй. Sunrise → Нар → гадагш хурдасгал → астероид → Бархасбадь → Санчир → Энцелад → Voyager гэсэн дараалал, урагш үргэлжлэх төгсгөлийг шалгана.

**Гарах нөхцөл:** эхлүүлэхээс төгсгөл хүртэл гацаагүй тоглох; pause болон chapter seek-ийн дараа хөдөлгөөн, текст нэг цагтай байх; эцэст автоматаар loop хийхгүй.

## P4 — Онцлох кадруудыг чанаржуулах

1. Дэлхийн шөнө, хотын гэрэл, нар мандах зах.
2. Нарны гадаргуу, prominence, нуман flyby, гадагш чиглэлийн эргэлт.
3. Астероидын аюулгүй коридор, instancing, cockpit сүүдэр.
4. Бархасбадийн өргөн зурвас, Их улаан толбо, гадна хөлгийн хэмжээ.
5. Санчирын цагираг, мөсөн ширхэг, гадна хөлгийн оргил кадр.
6. Энцеладын мөсөн гадаргуу, ан цав, plume flyby.
7. Voyager-ийн танигдах model, жижиг болсон Нар, дараагийн аяллын хаалга.

**Гарах нөхцөл:** кадр бүр өөрийн сүртэй шинжтэй; бүх хэсэг ижил planet shader-ийн өнгө солилт мэт харагдахгүй; asset төсөв хэтрээгүй.

## P5 — Эффект ба дууг найруулах

CSS warp, thruster, scanline-ийг зохистой хэмжээнд хийнэ. Дууны cue-үүдийг main time-тай синк хийнэ. Хүчтэй эффектгүй тайван завсар байгаа эсэхийг шалгана.

**Гарах нөхцөл:** mute, pause, resume зөв; repeated seek үед audio node давхар үүсч чангардаггүй; reduced motion хувилбар бүрэн ажиллана.

## P6 — Төхөөрөмж ба хүртээмж

320 px утаснаас проекторын хэмжээнд framing өөрчилнө. Чанар автоматаар бууруулах, WebGL context loss, tab pause, keyboard focus, contrast, текст томруулахыг шалгана.

**Гарах нөхцөл:** заавал байх шалгуурт уналтгүй; зорилтот гүйцэтгэл хүрээгүй бол аль төхөөрөмж/хэсэгт хязгаар байгааг тайланд тодорхой тэмдэглэнэ.

## P7 — Хүргэлт ба ангийн rehearsal

Интернэтийг хааж, цэвэр browser profile-оос эхлүүлж үзнэ. Багшийн төхөөрөмж, проектор, дууны түвшин, бүтэн дэлгэцийг шалгана. Дууссан кодыг шалгасан яг хувилбараар багцална.

**Ирээдүйн хүргэлт:**

- Ажиллуулах локал багц, шаардлагатай vendor/assets; эх код нь төслийн засвар үйлчилгээний материал бөгөөд сурагчдад тараахгүй.
- Нээх заавар, лиценз, эх сурвалж.
- Богино үзүүлэх заавар; эх кодын хичээл, даалгаваргүй.
- Бодит тестийн тайлан, screenshot-ууд.
- Интернэтгүй ашиглах багц.
- Hosted хувилбар зөвхөн дараа шаардсан хүрээнд.

## Чанар–хэмжээ–хугацааны шийдвэр

Хэрэв хугацаа багасгах шаардлага гарвал фото-бодит detail, нэмэлт гадна кадр, жижиг telemetry-г эхэлж цөөлнө. Нэг хөлгийн аяллын уялдаа, Санчирын оргил кадр, pause/reduced motion/offline ажиллагааг хасахгүй. Шинээр feature нэмэх бүрд хугацаа ба GPU төсөвт нөлөөг тэмдэглэнэ.
