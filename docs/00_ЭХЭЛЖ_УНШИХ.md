# ОДИССЕЙ / 01 — төслийн баримт бичиг

**Төслийн нэр:** ОДИССЕЙ / 01 — Хязгааргүй рүү\
**Огноо:** 2026-11-12\
**Баримтын хувилбар:** 1.4 — GitHub репозиторийн эхний бүтэц ба docs байрлал\
**Одоогийн үе шат:** баримт бичиг, GitHub холболт, репозиторийн эхний бүтэц. Demo-ийн хэрэгжүүлэлт эхлээгүй.

Энэ багц нь сурагчдад үзүүлэх, нэг сансрын хөлгийн тасралтгүй аяллын веб үзүүлэнг хэрхэн бүтээхийг тодорхойлно. Энэ `docs/` хавтаст төслийн 11 баримт байна. Репозиторийн root-д README, ажлын зарчим, Git тохиргоо болон ирээдүйн эх код/материалын хоосон хавтаснууд байрлана. Ажиллах demo, татсан сан, 3D model, texture, аудио хараахан байхгүй. Хэрэглэгч репозиторт эхний commit хийж push хийхийг хүссэн; энэ нь бүрэн demo-г хэрэгжүүлэх эсвэл вебээр нийтлэх ажил биш.

## Хэрэглэгчийн тогтоосон чиглэл

- Монгол хэлтэй, сурагчдад сэдэл өгөхүйц, «woow» гэмээр үзүүлэн байна.
- HTML, CSS нь бүтээлийн тулгуур: үндсэн бүтэц, зохиомж, хэв маяг, харагдах эффектүүдийн бодит хэсгийг хариуцна. Бүх бүтээлийг JavaScript, React эсвэл нэг canvas дотор хийж, HTML/CSS-ийг нимгэн гадна бүрхүүл болгохгүй.
- Шаардлагатай бүх технологи, сан, 3D model, texture, аудио, хэрэгслийг нэмэлтээр ашиглаж болно. Нэрлэсэн технологиуд нь жишээ; зөвшөөрөгдсөн зүйлсийн хаалттай жагсаалт биш. React, GSAP болон бусад санг хориглоогүй.
- Нэг хөлгийн бүхэл бүтэн аялал байна. Гаригийн жагсаалт, тус тусдаа ажилладаг үзүүлэнгийн цуглуулга болгохгүй.
- Технологи салгаж асаах/унтраах, CSS лаборатори руу үсрэх зэрэг үйлдлээр аяллын мэдрэмжийг таслахгүй.
- Эхний бүтээгдэхүүний хувилбар V1 нь нарны аймгийн аялал: Дэлхийн нар мандах эхлэл → Нарны flyby → гадагш хурдасгал → астероидын бүс → Бархасбадийн шуурга → Санчирын цагираг → Энцеладын мөсөн оргилуур → алсын бүс дэх Voyager-ийн уран сайхны уулзалт.
- V2-д ойрын одны систем ба аварга улаан од; V3-д оддын мананцар; V4-д хар нүх нэмэхээр үе шатлана. Ирээдүйн үзэгдлүүдийг V1-д хэрэгжүүлэхгүй.
- Responsive, интерактив, хөдөлгөөн багасгах болон гүйцэтгэлийн хувилбартай, offline ашиглах боломжтой байхаар төлөвлөнө.
- Одоо Desktop дээр шинэ хавтас үүсгэж, эхлээд зөвхөн төслийн бичиг баримтыг хийнэ.
- Энэ нь сонирхол төрүүлэх үзүүлэн. Сурагчдад эх код өгөх, код тайлбарлах, дагаж хийлгэх, даалгавар өгөх шаардлагагүй. Сонгосон мөчийг богинохон харуулаад дуусгаж болно.

## Технологийн сонголтын зарчим

Зорилго нь сурагчдад HTML + CSS ашиглан ийм гайхалтай орчин бүтээж болдгийг бэлэн үр дүнгээр харуулах. Нэмэлт технологи нь энэ суурийг өргөжүүлнэ. Ямар сан ашигласан тоо, кодын мөрийн хувь тогтоохгүй; үндсэн бүтэц, зохиомж, cockpit, гэрэл, хөдөлгөөний утгатай хэсгийг HTML/CSS бодитоор хариуцдаг байна. Энэ нь бүтээлийн дотоод архитектурын зарчим; сурагчдад эх код үзүүлэх эсвэл тараах шаардлага биш.

Баримт дахь Three.js, native JavaScript, Web Audio болон хувилбарын нэрүүд нь техникийн эхний санал. Хэрэглэгч тэдгээрийг заавал ашиглах эсвэл бусдыг хориглох нарийн хүрээ тогтоогоогүй. Эцсийн сонголтыг аяллын чанар, HTML/CSS-ийн бодит үүрэг, гүйцэтгэл, offline шаардлагад тулгуурлан хийнэ.

## Гол бүтээлч шийдэл

Үзэгч «ОДИССЕЙ / 01» хөлөгт сууж, Дэлхийн шөнийн зах дээр нар мандахыг харна. Эхлээд Нар руу очиж, түүний хажуугаар нумлан эргээд гаднах нарны аймаг руу ниснэ. Санчирын цагираг ба Энцеладын оргилуур V1-ийн сүртэй оргил болно. Voyager-ийн богино уулзалт, алсад жижигхэн болсон Нар бүхий кадраар V1 төгсөнө. Дэлхий рүү буцахыг V1-ийн төгсгөл болгохгүй; цааш явах мэдрэмжийг хадгална.

V1-ийн санал болгосон бүтэн хугацаа **5 минут 40 секунд**, **найман бүлэг**. Энэ хугацаа нь найруулгын санал; хэрэглэгчийн тогтоосон секундийн шаардлага биш. Бүлгүүд нэг дэлгэц, нэг хөлөг, нэг үндсэн цагаар холбогдоно. Гелиопауз нь нарны аймгийн бүхэл хязгаар биш тул Voyager-ийн мөчийг «нарны аймгаас бүрэн гарлаа» гэж шошголохгүй.

## Бүтээгдэхүүний хувилбарууд

| Хувилбар | Хүрээ | Төлөв |
|---|---|---|
| V1 | Дэлхий → Нар → гаднах гаригууд → Энцелад → Voyager / алсын бүс | Эхний хэрэгжүүлэх хүрээ |
| V2 | Нарны аймгаас цааш үсрэлт → ойрын одны систем → аварга улаан од | Дараагийн өргөтгөлийн санал |
| V3 | Оддын мананцар | V2-ийн дараах өргөтгөлийн санал |
| V4 | Хар нүх; нийт аяллын эцсийн найруулга | Дараагийн өргөтгөлийн санал |

Дараагийн үзэгдлүүдийг үе шаттай хийхийг хэрэглэгч тогтоосон. V2–V4 болгон яг ийн бүлэглэх нь энэ баримтын санал. Баримтын 1.4 гэдэг дугаар нь demo-ийн V4 гэсэн утга биш.

Бүтэн хугацаагаар үзүүлэх албагүй. 30–60 секундийн онцлох хэсэг эсвэл нэг кадрыг үзүүлээд өнгөрч болно. Тусдаа 12–15 минутын хичээл, кодын walkthrough, сурагчийн ажил энэ төслийн гаралт биш.

## Баримтын төлөвийг хэрхэн ойлгох вэ?

**Шаардлага:** хэрэглэгчийн шууд хэлсэн зүйл. Хэрэгжүүлэхдээ заавал баримтална.\
**Тогтсон хүрээ:** V1-д нарны аймаг, дараагийн хувилбаруудад од хоорондын үзэгдэл; Нарны flyby болон сонгосон гурван нэмэлт мөч.
**Санал болгосон шийдэл:** секундчилсэн хугацаа, камерын нарийн зам, нэр, сангийн сонголт болон V2–V4-ийн нарийн багцлалт. Эдгээрийг хэрэглэгчийн баталсан нарийн заавар гэж үзэхгүй.\
**Зорилтот үзүүлэлт:** хэмжиж шалгах ёстой гүйцэтгэл, хэмжээ, чанарын босго. Одоогоор хэмжиж баталсан үр дүн биш.
