# 01. Үзэл баримтлал ба хамрах хүрээ

## Нэг өгүүлбэрээр

Үзэгч нэг хөлгөөр Дэлхийгээс Нар руу очоод, гадагш эргэн Санчир, Энцелад, Voyager хүртэл аялахаар төсөөлж, вебээр ямар гайхалтай орон зай бүтээж болдгийг мэдэрнэ. Энэ нь V1; од хоорондын аялал дараагийн хувилбараас эхэлнэ.

## Гол зорилго

Үзүүлэнг хальт харсан ч сурагч «вебээр ийм гоё зүйл хийж болдог юм байна» гэж бодох нь хангалттай. Гол зорилго нь гайхшрал, сонирхол, сэдэл. Дараа нь код тайлбарлах, технологи заах, дагаж хийлгэх үүрэг байхгүй.

### Үзэгчид үлдэх сэтгэгдэл

1. Веб хуудас орон зай, хөдөлгөөн, кино мэт мэдрэмж өгч чаддаг.
2. HTML + CSS нь сонирхолтой бүтээлийн жинхэнэ тулгуур болж чаддаг.
3. Нэг сансрын хөлгийн аялалд орсон мэт гайхшрал төрнө.
4. Хүсвэл өөрөө цааш сонирхох сэдэл авна; даалгавар, хэмжих сургалтын үр дүн шаардахгүй.

## HTML + CSS тулгууртай бүтээл гэсэн утга

Үндсэн HTML нь орчны бүтэц, утга, удирдлагыг агуулна. CSS нь зөвхөн товч, font-ийн өнгө биш: cockpit, зохиомж, шил, гэрэл, оддын эффект, warp болон шилжилтийн утгатай хэсгийг бүтээнэ. JavaScript, React, animation library, 3D engine, shader, бэлэн model/texture, аудио болон бусад шаардлагатай технологийг нэмэлтээр ашиглаж болно.

Хэрэглэгч технологийн хаалттай жагсаалт эсвэл «энэ санг хориглоно» гэсэн хүрээ тавиагүй. Шалгах зүйл нь тухайн хэрэгсэл бүтээлийг сайжруулж байгаа эсэх, HTML/CSS тулгууртай бүтээл харуулах зорилгыг хадгалж байгаа эсэх юм. Бүх дүрслэл, бүтэц, эффект JS/React дээр төвлөрч, HTML/CSS нь зөвхөн эхлүүлэх бүрхүүл болсон шийдэл энэ зорилгод нийцэхгүй. Энэ шалгалтыг хөгжүүлэлтийн дотоод хяналтаар хийнэ; сурагч код авахгүй.

## Үзэгч ба ашиглах нөхцөл

- Үндсэн үзэгч: HTML/CSS суралцаж буй сурагчид. Насыг тусгайлан тогтоогоогүй тул хүүхдийг бага насных гэж үзэж хэт энгийн хэллэг хэрэглэхгүй.
- Үндсэн хэрэглээ: багшийн компьютерээс проектор эсвэл том дэлгэцээр үзүүлэх.
- Responsive дэмжлэг: шаардлагатай бол утас, laptop дээр нээж үзэх боломжтой; сурагч бүрт тараах сургалтын багц шаардахгүй.
- Дуугүй үзсэн ч үйл явдал, заавар ойлгогдоно.
- Эхний үзүүлэн интернэтгүй анги дээр ажиллахаар бэлтгэгдэнэ.

## Бүтээлийн амлалт

**Нэг хөлөг. Нэг замнал. Нэг оргил мөч.**

Хөлөг өөр өөр түвшний demo руу орж гарч байгаа мэт харагдахгүй. Дэлгэцийн үндсэн хүрээ, тэмдэглэгээ, хөлгийн нэр, хөдөлгүүрийн авиа, сансрын гэрэл нь бүх аяллыг холбоно. Гариг солигдох нь хуудас солигдож байгаа мэт биш, хөлөг нэг газраас нөгөөд очсон мэт мэдрэгдэнэ.

## Зохиолын нум — V1

| Үе | Мэдрэмж | Үүрэг |
|---|---|---|
| Дэлхийн шөнө → нар мандах | Танил, тайван, хүлээлт | Гэрээс гарах эхлэл |
| Нарны flyby | Дулаан, дүрэлзсэн, үлэмж | Эхний том зорилго |
| Гадагш хурдасгал | Эрч, догдлол | Дотроос гадагш чиглэлээ өөрчлөх |
| Астероид | Оролцоо, ойр өнгөрөлт | Өөрийгөө нисгэгч гэж мэдрэх |
| Бархасбадь | Аварга хүч | Шуурга ба хэмжээг мэдрэх |
| Санчирын цагираг | Гоо зүй, бишрэл | V1-ийн том оргил кадр |
| Энцелад | Цагаан мөс, оргилуур, хөдөлгөөн | Цагирагийн орчноос үргэлжилсэн шинэ мэдрэмж |
| Voyager, алсын Нар | Нам гүм, хүний утга, цааш тэмүүлэх | Дараагийн аяллын хаалга |

## Хувилбарын хүрээ

**V1-д зөвхөн нарны аймгийн сонгосон онцлогууд орно.** Сар, Буд, Сугар зэрэг биет заавал тусдаа бүлэг болохгүй. Хэрэгтэй бол арын богино дүрс байж болно. Нэмэлт сүүлт одны уулзалтыг энэ хувилбарын шаардлага болгохгүй.

V2-д ойрын од ба аварга улаан од, V3-д мананцар, V4-д хар нүх гэсэн өргөтгөлийг санал болгоно. Хөлөг, cockpit, удирдлага, аяллын цаг нь цааш нэг бүтээл болж үргэлжилнэ. V1-ийг хүлээж авахын тулд ирээдүйн үзэгдлүүдийг хүлээхгүй.

V1-ийн төгсгөл нь гэртээ буцах кадр биш, гадагш үргэлжлэх замнал. Дэлхийдээ буцах боломжийг нийт аяллын хожмын төгсгөлд дахин авч үзэж болно; одоогийн хувилбарт үүрэг болгохгүй.

## Заавал байх зүйл

- Нислэгийн нэг cockpit; гадна кадрт ижил хөлөг.
- Автоматаар бүтэн тоглох үндсэн аялал.
- Үзэгч аяллыг түр зогсоож, үргэлжлүүлж, бүлэг давтаж үзэх боломж.
- Дэлхийн нар мандах эхлэл, Нарны flyby, гадагш чиглэсэн уран зөгнөлт хурдасгал, астероидын бүс, Бархасбадийн шуурга, Санчирын цагираг, Энцеладын оргилуур, Voyager-ийн богино мөч.
- CSS-ээр хийсэн бодит харагдах эффектүүд.
- Аяллын хүрээнд тохирох богино ажиглалтын мэдээлэл.
- Гар, mouse, touch удирдлага.
- Хөдөлгөөн багасгах, бага чадлын болон WebGL ажиллахгүй үеийн хувилбар.
- Монгол кирилл үсэг зөв гарах, уншихад хялбар бичвэр.
- Үзүүлэхэд зориулсан товч заавар, төслийн дотоод эх сурвалжийн жагсаалт.

## V1-д орохгүй зүйл

- Буудлага, дайсан, дэлбэрэлт, оноо, амь, ялагдалтай тоглоом.
- Гариг бүрийн тусдаа хуудас, каталог, урт encyclopedia.
- Аяллын үеэр CSS/WebGL сэлгэх технологийн танилцуулгын самбар.
- Бүртгэл, нэвтрэлт, хэрэглэгчийн өгөгдөл, backend, төлбөр, analytics.
- Бүх нарны аймгийг бодит хэмжээ, бодит хугацаагаар симуляцлах.
- Ойрын од, аварга улаан од, мананцар, хар нүх: дараагийн хувилбаруудад хамаарна.
- VR/AR, олон тоглогч, чөлөөт 6 тэнхлэгийн нислэг.
- Урт яриатай AI туслах, online speech synthesis.
- Алдарт киноны хөлөг, дуу, лого хуулбарлах.
- Сурагчдад эх код тараах, кодын walkthrough, дасгал, даалгавар, сургалтын модуль.

## Амжилтыг юугаар таних вэ?

Үзэгч нэг удаа эхлүүлэхэд зохиол бүрэн тоглоно; эсвэл багш онцлох хэсгийг богинохон үзүүлж болно. Сүртэй кадруудыг үзэхийн тулд олон тохиргоо оролдох шаардлагагүй. Нэг өгүүлбэрээр HTML/CSS тулгууртай, нэмэлт технологи ашигласан бүтээл гэж үнэн зөв хэлэхэд хангалттай. Хэрэглэгч нэг бүхэл, гайхалтай сансрын аялал харна. Эх код авах, технологи тайлбарлуулах нь амжилтын шалгуур биш.
