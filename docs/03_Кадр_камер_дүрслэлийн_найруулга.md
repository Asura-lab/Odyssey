# 03. Кадр, камер, дүрслэлийн найруулга

## Дүрслэлийн чиглэл

Тоглоомын өнгө алаг дэлгэцээс илүү судалгааны хөлгийн бодитой, нам гүм бүхээг. Гүн хар-хөх сансар, мөсөн цэнхэр багаж, зэс-алтан хөдөлгүүрийн дохио. Гол анхаарал нь цонхны цаадах ертөнцөд байна.

Гэрэлтдэг бүх зүйлийг хамгийн тод болгохгүй. Гаригийн гэрэл cockpit-ийн захад тусах нь хоёр давхаргыг нэг орон зай болгож холбоно. Нарны үед тод алт-улбар, Бархасбадийн үед дулаан хүрэн, Санчирын үед зөөлөн алт, Энцеладын үед мөсөн цайвар, Voyager-ийн төгсгөлд нам гүм хөх хар өнгө давамгайлна.

## Өнгөний суурь

| Үүрэг | Өнгө | Ашиглах газар |
|---|---|---|
| Сансрын хар | `#040910` | Үндсэн дэвсгэр, гүн |
| Бүхээгийн хөх саарал | `#0C1924` | Хөлгийн хүрээ, удирдлагын тавцан |
| Мөсөн цэнхэр | `#ACDFEC` | Идэвхтэй зам, чиглэл, үндсэн гэрэл |
| Цайвар бичвэр | `#E5EDF0` | Гарчиг, чухал үг |
| Бүдэг багажийн өнгө | `#8097A5` | Хоёрдогч мэдээлэл |
| Зэс туяа | `#E7A57A` | Хөтлүүрийн дохио, орчны дулаан гэрэл |

Эдгээр нь санал болгосон эхлэл. Уншигдах байдал нь өнгөний үнэнч байдлаас чухал; бодит contrast хэмжилтээр тохируулна.

## Үсгийн сонголт

- Гол гарчиг: Bahnschrift; байхгүй бол Segoe UI, Arial, sans-serif.
- Монгол тайлбар: Segoe UI → Arial → sans-serif.
- Багажийн тоо, цаг, тэмдэглэгээ: Consolas → Courier New → monospace.
- Гаднаас font татахгүй. Зөвхөн нэр нь гоё харагдах гээд кирилл дутуу font ашиглахгүй.
- Том дэлгэцийн гарчиг 48–72 px; тайлбар 16–18 px. Утасны гарчиг 30–40 px, үндсэн бичвэр хамгийн багадаа 14 px.
- Маш жижиг техникийн шошго зөвхөн чимэглэлийн шинжтэй байна; заавар, үйлдэл, агуулгыг түүгээр дамжуулахгүй.

## Cockpit-ийн бүтэц

```text
┌ хөлгийн нэр ───── холбоо / аяллын цаг ───── дуу · дэлгэц ┐
│                                                        │
│   бүлгийн богино үг                  гариг / орчин       │
│                                      ↗ чиглэлийн тэмдэг │
│                  НЭГ ТОМ ЦОНХ                          │
│                                                        │
│               хөлгийн богино мэдэгдэл                  │
├──────────── намхан удирдлагын тавцан ────────────────────┤
│     аяллын зам                                         │
│ өмнөх · түр зогсоох · дараах     явц     хурдасгах       │
└────────────────────────────────────────────────────────┘
```

Хажуу хүрээ нь доод хэсэгт өргөсөж, төвийн цонхыг хаахгүй. Доод тавцан trapezoid хэлбэртэй; `clip-path`, border, gradient, box-shadow-оор бүтээгдэнэ. Cockpit өөрөө зураг эсвэл видео биш тул өөрчлөх, зааж тайлбарлах боломжтой.

## Дэлгэцийн давхаргууд

| Давхарга | Агуулга | Үүрэг |
|---|---|---|
| 1. Алсын гүн | CSS алсын одод, бүдэг nebula | Хар сансрыг хоосон хавтгай болгохгүй |
| 2. 3D ертөнц | Гариг, цагираг, ойрын asteroid, хөлгийн гадна кадр | Камерын бодит perspective, гэрэл, далдлалт |
| 3. Атмосфер | CSS туяа, шилний тусгал, warp | Орчин ба хөлгийг уях |
| 4. Хөлгийн хүрээ | CSS cockpit, хажуу тулгуур, тавцан | Үзэгчийн тогтвортой орон зай |
| 5. Мэдээлэл | Чиглэл, богино үг, удирдлага | Үйлдэл ба өгүүлэмж |
| 6. Хэрэгцээний самбар | Ажиглалт, тохиргоо | Зөвхөн хүсэлтээр нээгдэх |

Ойр оддыг Three.js Points, алсын жижиг twinkle-ийг CSS давхарга хариуцна. Нэг оддыг хоёр технологиор давхар дүрслэхгүй. Warp үед ойрын 3D оддын энгийн хөдөлгөөнийг намсгаж, CSS зурвасыг гол болгоно.

## Камерын дүрэм

- Үндсэн камер: perspective, FOV 50°-аас эхэлж visual review-ээр тохируулна.
- Нэг кадрт бүх гаригийг зэрэг харуулахгүй.
- Тогтмол шугаман хөдөлгөөнөөс илүү ойртохдоо хурдаа бууруулж, сүртэй кадрт түр амсхийлгэнэ.
- Mouse/touch steer нь урьдчилан найруулсан үндсэн зам дээрх жижиг offset. Камерыг чөлөөт orbit болгохгүй.
- Cockpit-ийн хазайлт хэвийн үед 2° хүртэл; asteroid дахь bank 4° хүртэл. Хэт савлуулахгүй.
- V1-ийн гадна кадр гурван удаа: Дэлхийн эхлэл, Бархасбадийн хэмжээ, Санчирын оргил. Voyager-ийн мөчийг cockpit-оос зөөлөн ойртож харах кадраар шийднэ; нэмэлт гадна кадр заавал биш.
- Гадна кадрт cockpit зөөлөн харанхуйлж, кадрын захад уусна. Хөлгийн ижил нэр, дүрс, өнгө, хөдөлгүүр хадгалагдана.
- Reduced motion үед bank 0°, pointer parallax 0, warp орны өөрчлөлт 0. Камерын урт flyby-г удаан уусалттай үндсэн кадруудаар орлуулна.

## Responsive найруулга

### 16:9 / 16:10 компьютер, проектор

Цонх гол талбайг эзэлнэ. Гариг баруун эсвэл төвийн баруунд, богино бичвэр зүүнд. Удирдлага доод 20–24%-д багтана. Проектор дээр маш бүдэг шошго уншигдахгүй байвал агуулгыг томруулж, чимэглэлийг цөөлнө.

### Утасны босоо байрлал

Гаригийг зүгээр тайрахын оронд camera framing-ийг тусад нь тохируулна. Гол гарчиг дээд гуравны нэгт; гараар хүрэх удирдлага доод талд. Cockpit-ийн доод хэсэг намсана, хажуу telemetry алга болно. V1-ийн найман бүлэг, тоглуулах, pause, ажиглалт хэвээр байна.

### Утасны хэвтээ байрлал

Гарчиг богиносож, текстийн эзлэх орон зай буурна. Touch удирдлага доод буланд; системийн safe-area-г хүндэтгэнэ. Дэлгэц эргүүлэхийг албадахгүй.

## Хэрэглэхгүй найруулга

Гариг бүрийн өмнө том хар дэлгэц, loading spinner, navigation page гаргахгүй. Бүх дэлгэцийг байнга чичрүүлэхгүй. Хүчтэй RGB glitch, strobe, урт lens dirt, уншихын аргагүй microscopic HUD-г гол эффект болгохгүй. Эффектийн тооноос илүү нэг орон зайн итгэл төрүүлэх уялдааг чухалчилна.
