# 02. V1 — нарны аймгийн аяллын бүрэн зохиол

**Хүрээ:** зөвхөн нарны аймгийн онцлох үзэгдлүүд.\
**Санал болгосон бүтэн хугацаа:** 5:40, найман бүлэг. Богинохон сонгосон хэсгийг үзүүлж болно.\
**Өгүүлэх хэлбэр:** нэг хөлөг, нэг cockpit, богино бичвэр, орчны дуу.\
**Төгсгөл:** Voyager-ийн уран сайхны уулзалт, алсын Нар, цааш үргэлжлэх аяллын мэдрэмж.\
**Дараа:** ойрын од, аварга улаан од, мананцар, хар нүх V1-д тоглохгүй.

Хугацаанууд нэг үндсэн цагт хамаарна. Шилжилтүүд тухайн интервалд багтана. Pause үед цаг, камер, холбогдох CSS хөдөлгөөн ба дуу хамт зогсоно. Зай, хугацаа, хурд нь киноны найруулгаар шахагдсан; бодит нислэгийн симуляц биш.

## Аяллын өмнө — цаг эхлээгүй

Шөнийн Дэлхий, хотуудын бүдэг гэрэл, агаар мандлын нимгэн зах. Cockpit харанхуй боловч хүлээлгийн гэрэлтэй. Нарны гэрэл зах дээр цухуйх гэж байна.

**Гол үг:** «Эх дэлхийгээс хязгааргүй рүү.»\
**Үйлдэл:** «Аяллаа эхлүүлэх». Дуу анх унтраалттай.\
**Мэдрэмж:** юу болохыг хүлээлгэх; хурдан хөдөлгөөнгүй.

## Найруулгын дүрэм

1. Нэг удаад нэг гол харагдах үйл явдал; нэг орон зай, ижил хөлөг.
2. Гарчиг ихдээ хоёр мөр; дуугүй үед ч ойлгомжтой богино үг.
3. Хэсэг бүр өөр мэдрэмжтэй: Дэлхий — гэр; Нар — эрч; asteroid — оролцоо; Бархасбадь — хүч; Санчир — гоо зүй; Энцелад — мөсөн хөдөлгөөн; Voyager — хүний мөр.
4. CSS warp, cockpit, гэрэл, шил, шилжилтүүд нэмэлт 3D/аудиотой нэг цагт уялдана.
5. Reduced motion үед налалт, хурдасгал, ойрын ширхэгийн хөдөлгөөнийг тайван композици, уусалтаар орлуулна; үйл явдал үлдэнэ.
6. Сарны тусдаа бүлэг, Дэлхийдээ буцах төгсгөл өмнөх ноорогт байсан; V1-ийн энэ зохиолд орлохгүйгээр нэмэхгүй.
7. V2–V4-ийн зохиолыг V1-ийн хүргэлтийн өмнөх зайлшгүй ажил болгохгүй.
