# 04. Технологи ба архитектур

Эндхүү сонголтууд нь хэрэгжүүлэлтэд зориулсан нээлттэй санал. Хэрэглэгч HTML + CSS-ийг тулгуур болгох зарчим өгсөн; шаардлагатай нэмэлт технологийг нарийн жагсаалтаар хязгаарлаагүй. Энэ үе шатанд сан суулгах, код бичих, сервер ажиллуулахгүй.

## Заавал баримтлах архитектурын зарчим

1. HTML нь үндсэн орчны бүтэц, бичвэр, удирдлага, агуулгыг бодитоор агуулна.
2. CSS нь бүтээлийн зохиомж, хэв маяг, cockpit, гэрэл, материалын мэдрэмж, харагдах хөдөлгөөний утгатай хэсгийн эзэн байна.
3. JavaScript болон бусад хэрэгсэл нь оролт, синк, өгөгдөл, 3D, shader, дуу зэрэг нэмэлт боломжийг өгнө. Шаардлагатай ажлыг хийж болно; бүх бүтээлийг тэдгээрт шилжүүлэхгүй.
4. Нэг canvas эсвэл React root-ийг бүх бүтээл болгож, HTML/CSS-ийг зөвхөн хуудас нээх бүрхүүл болгохгүй.
5. Кодын мөрөөр HTML/CSS/JS-ийн хувь тогтоохгүй. Үүрэг, харагдах үр дүнг хөгжүүлэлтийн дотоод хяналтаар шалгана. Сурагчид код авах, өөрчлөх шаардлагагүй.

## Технологи сонгох шалгуур

Нэмэлт хэрэгсэл аяллын чанарт тодорхой ашигтай, HTML/CSS суурийг хадгалсан, төхөөрөмжийн төсөвт багтсан, offline хүргэлтэд тохирсон бол хэрэглэж болно. Нэг үүргийг олон давхар сангаар давхардуулахгүй; харин шаардлагатай хэрэгслийг урьдчилан хориглохгүй.

## Технологийн эхний санал — хаалттай жагсаалт биш

| Технологи | Сонголт | Тодорхой үүрэг |
|---|---|---|
| HTML | Semantic HTML, native button/dialog | Бүтэц, бичвэр, удирдлага, accessibility |
| CSS | Native CSS, custom properties, Grid/Flex, keyframes | Бүхээг, гэрэл, шил, HUD, warp, UI шилжилт, responsive |
| JavaScript | Native ES modules эхний санал; шаардлагатай сан нэмэх боломжтой | Аяллын нэг цаг, төлөв, камер, оролт, pause/resume, тохиргоо |
| Three.js | **0.187.0 / r187** нь шалгасан нэр дэвшигч; эцсийн сонголт биш | Sphere, ring, asteroid, хөлөг, 3D камер, гэрэлтүүлэг |
| GPU API | Three.js сонговол WebGLRenderer / **WebGL 2**; өөр тохирох renderer сонгож болно | 3D зурлагыг GPU-д гаргах |
| Shader | Жижиг GLSL ShaderMaterial шаардлагатай газарт | Агаар мандлын ирмэг, шуурганы UV хөдөлгөөн |
| Audio | Native Web Audio API | Хөдөлгүүр, warp, navigation дохиог синтезлэх |
| SVG | Өөрийн локал SVG | Хөлгийн тэмдэг, icon, жижиг схем |
| Font | Системийн кирилл font fallback | Интернетгүй уншигдах Монгол бичвэр |
| Development preview | Python 3 static HTTP server, localhost | Module болон asset-ийг локал HTTP-ээр өгөх |
| Verification | Node.js test runner + Playwright | Төлөв, удирдлага, browser screenshot, offline шалгалт |

Three.js-ийн r187 package-д `0.187.0` гэж тэмдэглэсэн тул энэ хувилбарыг боломжит суурь болгон шалгасан. Энэ нь хэрэглэгчийн тогтоосон шаардлага биш. Хэрэгжүүлэлт эхлэхэд тохирох сан, хувилбарыг сонгож, сонгосон dependency-уудыг тогтооно. [Албан ёсны package](https://raw.githubusercontent.com/mrdoob/three.js/r187/package.json)

WebGLRenderer нь WebGL 2 ашигладаг; WebGL 1-ийг энэ багцын 3D горимын fallback гэж амлахгүй. Дэмжихгүй төхөөрөмжид CSS хувилбар хэрэглэнэ. [Three.js WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html)

## Шаардлагатай үед ашиглаж болох нэмэлт хэрэгслүүд

| Хэрэгсэл | Ашиглаж болох үүрэг | HTML/CSS суурьтай уялдах нөхцөл |
|---|---|---|
| GSAP эсвэл өөр animation library | Нарийн timeline, camera interpolation, CSS эффектүүдийн синк | CSS-ийн эзэмшдэг эффектүүдийг бүхэлд нь JS зурлагаар солихгүй; нэг үндсэн цагтай байна |
| React/Vue эсвэл өөр framework | Үнэхээр хэрэгтэй туслах самбар, төлөвийн UI, тусгаарласан хэсэг | Бүх хуудсыг framework component-д төвлөрүүлэхгүй; үндсэн HTML/CSS-ийн бодит үүрэг хадгалагдана |
| Tailwind/Bootstrap эсвэл өөр CSS хэрэгсэл | Туслах layout, хэрэгтэй utility | Өөрийн CSS загвар ба эффектүүдийн тулгуур үүрэг тодорхой үлдэнэ |
| WebGPU, өөр 3D engine, shader хэрэгсэл | Тусгай 3D чанар, дүрслэлийн шаардлага | Төхөөрөмжийн дэмжлэг, fallback, offline ажиллагааг шийднэ |
| Physics engine | Тодорхой scene-д хэрэгтэй хөдөлгөөн | Зохиолын аюулгүй авто аялал, гүйцэтгэлийг хадгална |
| Blender, glTF/GLB, texture боловсруулах хэрэгсэл | Өндөр чанартай хөлөг, материал, орчин | 3D нэмэлт давхарга нь HTML/CSS орчныг дэмжинэ |
| Audio library, локал хөгжим/эффект, narrator | Орчны мэдрэмж ба өгүүлэмж | Эрх нь тодорхой, дуугүй үзэх боломжтой, offline файлтай |
| Backend/API эсвэл өөр үйлчилгээ | Тодорхой шинэ хэрэгцээ гарсан үед | Одоогийн үзүүлэх аяллын offline замыг үйлчилгээний хамааралтай болгохгүй |

Энэ хүснэгт ч мөн бүрэн жагсаалт биш. Нэмэлт санг зөвхөн нэрнээс нь болж хориглохгүй. Online font/CDN/API ашиглавал ангид үзүүлэх offline хувилбарт шаардлагатай материал, орлуулах замыг хамт бэлтгэнэ.

## HTML + CSS ба нэмэлт боломжийн бодит зааг

| Элемент | HTML/CSS юу хийх вэ? | Нэмэлт технологи юу хийх вэ? |
|---|---|---|
| Cockpit | Хүрээ, шил, тавцан, гэрэл, багаж, налалт | JS төлөвтэй нь уялдуулна |
| Warp | Perspective, transform, зурвас, keyframes | JS эхлэх/зогсох цагийг өгнө; дууг Web Audio хийнэ |
| Одод | Алсын twinkle, давхаргын шилжилт | Ойрын spatial оддыг Three.js Points хийнэ |
| Гариг, Нар | CSS fallback сфера, glow, уусалт, бүхээгт тусах орчны өнгө | Нэмэлт renderer-ээр sphere, texture, Нарны гадаргуу ба плазмын нум |
| Санчирын цагираг | Хөнгөн хувилбарын ташуу дүрслэл | 3D ring geometry, camera perspective, depth occlusion |
| Астероид | Cockpit bank, fallback хажуугийн чулуун дүрс | 3D чулуулгийн depth ба flyby |
| Удирдлага | Button, focus, hover, responsive байрлал | JS дараалал, seek, pause, keyboard |
| Энцелад, Voyager | Шилний гэрэл, мэдээллийн шошго, уусалт | Нэмэлт particle plume ба аппаратын model |
| Дуу | HTML-д дууны удирдлага байрлана | Web Audio эсвэл сонгосон локал audio хэрэгсэл |

**Сурагчдад өгөх гол санаа:** «HTML + CSS ашиглан ийм гайхалтай орчин бүтээж болно.» Үндсэн бүтэц, зохиомж, cockpit, гэрэл, харагдах эффектүүдийн утгатай хэсэг HTML/CSS дээр байна. Үүнийг сурагчдад код задлан үзүүлэхгүйгээр бэлэн үзүүлэнгээр мэдрүүлнэ. Нэмэлт 3D, удирдлага, синк, дууны хэрэгслийг төслийн дотоод баримтад үнэн зөв бүртгэнэ. Асуувал HTML/CSS тулгууртай, нэмэлт хэрэгсэл ашигласан гэж товч хэлнэ; «нэг ч JS/3D сан ашиглаагүй» гэх худал мэдэгдэл хийхгүй. Үзэгчийн гол дэлгэц дээр технологи салгах самбар байхгүй.

Дээрх үүргийн хүснэгт нь эхний саналын жишээ; Three.js эсвэл Web Audio-г заавал сонгох тогтоол биш. Хэрэгсэл өөрчлөгдсөн ч HTML/CSS-ийн тулгуур үүрэг хадгалагдана.

CSS `rotateX` эсвэл perspective нь элементэд 3D байрлалын мэдрэмж өгдөг; 3D mesh-ийн гэрэл, гадаргуу, depth buffer-ийн бүх үүргийг өөрөө гүйцэтгэдэг гэж тайлбарлахгүй.

## Системийн уялдаа

```text
Үзэгчийн үйлдэл
      ↓
Journey Controller ── нэг үндсэн цаг / төлөв
      ├── HTML бичвэр, мэдэгдэл, progress
      ├── CSS custom properties, animation төлөв
      ├── нэмэлт 3D engine-ийн camera, объект, гэрэл
      └── сонгосон audio хэрэгслийн дуу, gain, дохио
```

Олон тусдаа timer-аар хэсгүүдийг ажиллуулахгүй. Нэг цагийн дагуу гаригийн байршил, CSS эффект, дуу, бичвэрийг тооцно. Хугацааны утгаар шууд сэргээж болдог тул бүлэг рүү очих, pause, restart найдвартай байна.

## Хувилбараар өргөжүүлэх бүтэц

V1 нь нарны аймгийн найман бүлэгтэй, бие даан бүрэн тоглоно. Бүлгийн хугацаа, орчин, бичвэр, cue-г өгөгдлөөр тодорхойлж, хөлөг/cockpit/controller-ийг дахин ашиглахаар санал болгоно. V2-ийн одод, V3-ийн мананцар, V4-ийн хар нүхийг дараа шинэ орчин ба кадраар нэмж болно.

V1 эхлэхэд ирээдүйн хувилбарын shader, том texture, model, audio-г татахгүй. Бэлэн биш үзэгдлийн заавал ачаалах хамаарал эсвэл идэвхтэй хоосон navigation үүсгэхгүй. Хувилбар нэмэхэд ижил аяллын урсгал үргэлжлэх боловч V1-ийн offline багц өөрөө ажилладаг хэвээр байна.

## Төлөвийн загвар

| Төлөв | Утга | Дараагийн боломж |
|---|---|---|
| Бэлтгэж байна | Локал сан, зайлшгүй материал бэлдэж байна | Бэлэн эсвэл хөнгөн хувилбар |
| Бэлэн | Эхлэхийг хүлээнэ | Тоглож байна |
| Тоглож байна | Аяллын цаг урагшилна | Pause, ажиглалт, дууссан |
| Түр зогссон | Цаг, камер, хамаарах CSS/дуу зогсоно | Үргэлжлүүлэх, бүлэг сонгох |
| Ажиглаж байна | Богино мэдээлэл нээлттэй, аялал pause | Өмнөх play/pause төлөвт буцах |

Дүрслэлийн чанар болон reduced motion нь тусдаа тохиргоо. Чанар өөрчлөгдөхөд аяллын цаг, бүлэг, зохиол шинэчлэгдэж эхнээсээ тоглохгүй.

## Санал болгосон эх кодын бүтэц — одоо үүсгэхгүй

```text
odyssey/
  index.html
  styles/
    base.css            утга, өнгө, responsive, accessibility
    cockpit.css         хөлгийн хүрээ, багаж, шил
    effects.css         warp, thruster, transitions, fallback
  scripts/
    main.js             эхлэлт, capability шалгалт
    journey.js          нэг цаг, бүлэг, төлөв
    input.js            mouse, touch, keyboard
    renderer.js         сонгосон нэмэлт 3D renderer ба camera
    worlds.js           гариг, цагираг, астероид
    audio.js            Web Audio
    ui.js               бичвэр, самбар, удирдлага
  assets/
    textures/           төсөл дотор үүсгэсэн texture
    svg/                өөрийн icon, тэмдэг
  vendor/
    three/              Three.js сонгосон тохиолдлын локал module
    licenses/           MIT болон ашигласан бусад лиценз
  docs/                 энэ төслийн шинэчилсэн баримтууд

```

Энэ нь нэг боломжит бүтэц; сонгосон нэмэлт хэрэгслээс хамаарч өөрчилж болно. Одоогийн Desktop багцад эдгээр code/assets хавтас орохгүй.

## Offline ажиллагааны нарийн утга

Offline гэдэг нь **интернэтгүй үед локал HTTP-ээр ажиллана** гэсэн шаардлага. Сонгосон нэмэлт сангуудын шаардлагатай module, model, texture, SVG, аудио бүгд offline багцад байна. Энэ хувилбарын run-time нь CDN, remote texture, online API, telemetry-ээс хамаарахгүй.

Module/asset loading-ийг найдвартай ажиллуулахын тулд локал static server ашиглана. `index.html`-ийг `file://`-ээр давхар товшиж нээхэд бүрэн 3D заавал ажиллана гэж амлахгүй; server-гүй нээвэл CSS харагдац болон нээх заавар ойлгомжтой байна. Локал сервер ашиглах шаардлагыг Three.js-ийн [суулгах тайлбар](https://threejs.org/manual/pages/installation.html) мөн авч үздэг.

Service worker эхний хувилбарын зайлшгүй шаардлага биш. Локал файлууд бүрэн байгаа үед интернэтгүй ажиллахад service worker шаардахгүй. Hosted хувилбар нэмж хийх эсэхийг дараа тусад нь шийднэ.

## Pause ба цагийн сахилга

- Delta хугацааг идэвхтэй tab-ийн аяллын цагт л нэмнэ.
- Tab нуухад pause; буцаж ирэхэд хугацааг огцом нөхөж үсрэхгүй.
- CSS-ийн гол animation-уудыг play-state болон үндсэн цагтай синк хийнэ.
- Бүлэг рүү шилжихдээ тухайн мөчийн CSS phase, camera, audio төлөвийг хамтад нь тавина.
- Pause үед шинэ дохио дуугарахгүй; loop дууны gain-ийг намсгана эсвэл suspend хийнэ.
- Дуусахад автоматаар дахин эхлэхгүй.

## Дуу эхлэх нөхцөл

Хэрэглэгч дуу асаах эсвэл дуу зөвшөөрсөн эхлүүлэх үйлдэл хийх хүртэл AudioContext-ийг дуугаргахгүй. Browser autoplay бодлогоос үл хамааран эхний нээлт дуугүй байна. [MDN Web Audio best practices](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)

## Дараагийн хэрэгжүүлэлтэд батлах техникийн гарц

Эхлээд нэг гариг + HTML/CSS cockpit-ийн жижиг дотоод туршилтаар санал болгосон нэмэлт хэрэгслүүдийн хэрэгцээ, Монгол font, локал ачаалалт, shader ба fallback замыг шалгана. Сонголтыг HTML/CSS-ийн бодит үүрэг, аяллын чанар, гүйцэтгэлээр батална. Энэ туршилтыг хэрэглэгчид бэлэн demo гэж танилцуулахгүй. Үүний дараа нэг master timeline дээр бүх аяллыг угсарна.
