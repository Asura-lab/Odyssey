# 05. Удирдлага ба дэлгэцийн урсгал

## Үндсэн зарчим

Нэг удаа «Аяллаа эхлүүлэх» дарахад бүх аялал үргэлжилнэ. Үзэгч зааврыг судалж дуусаагүй байсан ч гоё кадруудыг үзнэ. Удирдлага нь аялалд оролцох боломж нэмнэ; үргэлжлүүлэхийн тулд давах ёстой шалгалт биш.

## Үзэгчийн үндсэн замнал

1. Нээлт: Дэлхий ба бүхээг шууд харагдана. Материал бэлдэх шаардлагатай бол жижиг явцын мэдээлэл гарна.
2. Бэлэн: эхлэх товч, дуу асаах сонголт, дуугүй ч бүрэн үзэж болохыг ойлгоно.
3. Эхлүүлэх: дуу зөвшөөрсөн бол AudioContext идэвхжинэ; cockpit асаж, аяллын цаг эхэлнэ.
4. Аялал: найман бүлэг нэг орчинд үргэлжилнэ. Удирдлага намхан, анхаарал булаахгүй.
5. Оролцоо: харах чиглэлээ өөрчилж, asteroid дунд бага зэрэг залж, сонирхсон кадраа pause хийнэ.
6. Ажиглалт: хүсвэл тухайн биетийн богино мэдээлэл нээнэ. Хаахад өмнөх play/pause төлөвөө сэргээнэ.
7. V1-ийн төгсгөл: Voyager-ийн уулзалт, алсын Нар, урагш чиглэсэн хөлөг. Дахин аялах эсвэл бүлэг сонгох боломж. Ойрын од руу хараахан үсрэхгүй.

## Үндсэн удирдлага

| Үйлдэл | Дэлгэц | Гар | Утас | Үр дүн |
|---|---|---|---|---|
| Эхлүүлэх / pause / resume | Доод төв товч | Space | Товших | Нэг үндсэн цагийг өөрчилнө |
| Өмнөх бүлэг | Зүүн сум | ← | Товших | Өмнөх бүлгийн эхлэл |
| Дараах бүлэг | Баруун сум | → | Товших | Дараах бүлгийн эхлэл |
| Тодорхой бүлэг | Доод замын тэмдэг | Tab, Enter | Товших | Тэр бүлгийн эхлэл |
| Түр хурдасгах | Хөтлүүрийн товчийг дарах | W дарж барих | Товчийг барих | 2× хүртэл; тавихад 1× |
| Дуу асаах/унтраах | Дууны icon | M | Товших | Audio gain, icon, accessible label шинэчлэгдэнэ |
| Бүтэн дэлгэц | Дэлгэцийн icon | F | Browser дэмжвэл | Амжилтгүй үед богино тайлбар |

Хурдасгах нь бүх аяллын цагийг 2× болгох санал. Урт shader animation-ийг тусад нь гүйлгэхгүй. Товчийг дараад барих боломжгүй хэрэглэгчдэд тохиргоонд 1× / 2× сонголт байж болно. Warp товч дарах бүрд санамсаргүй газар teleport хийхгүй; зохиолын hyperdrive өөрийн цагтаа тоглоно.

Товчнуудын нэр, нэг үйлдлийн үг аяллын турш ижил байна. Эхний «Аяллаа эхлүүлэх» нь тоглож байх үед «Түр зогсоох», pause үед «Үргэлжлүүлэх», төгсгөлд «Дахин аялах» болно.

## Аяллын замын дүрслэл

V1-ийн найман цэг: Дэлхий → Нар → хурдасгал → астероид → Бархасбадь → Санчир → Энцелад → Voyager/алсын бүс. Нарийн замын шугам, одоогийн байрлал. Идэвхтэй бүлэг зөвхөн өнгөөр биш хүрээ, хэлбэр, бичвэрээр ялгарна. Бүлэг сонгох нь ижил дэлгэц дотор цагийг шилжүүлнэ. URL/page navigation үүсгэхгүй.

Дараах бүлэг рүү шууд шилжих нь шинээр богино уусалттай; хэрэглэгчийн сонгосон үед 20 секунд warp заавал үзүүлэхгүй. Pause төлөвтэй байхад бүлэг сонговол pause хэвээр үлдэнэ.

## Ажиглалтын самбар

Жижиг, тайван, тухайн орчинтой холбоотой. Ихдээ 60–90 Монгол үг; заавал нээх шаардлагагүй. Нээх үед камер, CSS хөдөлгөөн, аяллын цаг, scene audio-ийн идэвхтэй хэсэг зогсоно. Самбарт focus хязгаарлагдаж, хаахад нээсэн товч руу буцна.

| Бүлэг | Самбарын агуулга |
|---|---|
| Дэлхий | Шөнө, хотуудын гэрэл, агаар мандлын зах, нар мандах |
| Нар | Од, плазмын нум, уран сайхны ойртолт |
| Хурдасгал | Зохиомол hyperdrive; нарны аймгийн доторх шилжилт |
| Астероид | Гол бүс; киноны дүрслэлийг нягтруулсан |
| Бархасбадь | Үүлэн зурвас, Их улаан толбо |
| Санчир | Мөсөн хэсгүүдийн цагираг |
| Энцелад | Мөсөн хэсэг, усны уурын оргилуур |
| Voyager / алсын бүс | Хүн төрөлхтний аппарат; гелиосфер ба бүхэл нарны аймгийн хязгаарын ялгаа |

Дараагийн V2–V4-ийн бүлгийн товч, самбар V1-д идэвхтэй харагдахгүй. Төгсгөлд цааш зам байгаа мэдрэмж төрүүлэх богино үг байж болно; ажиллагаагүй «од руу үргэлжлүүлэх» товч байхгүй.

CSS-ийн техникийн тайлбарыг энэ самбарт чихэхгүй. Агуулга нь нислэгийн ажиглалт байна.

## Тохиргоо

- **Дуу:** анх унтраалттай.
- **Хөдөлгөөн багасгах:** системийн тохиргоог анх дагана. Хэрэглэгч илүү тайван хувилбарыг сонгож болно.
- **Дүрслэлийн чанар:** автомат / хөнгөн. «CSS vs WebGL» гэж нэрлэхгүй; шинэ demo нээхгүй.
- **Дахин эхлэх:** санамсаргүй дарах магадлал бага байрлалд байна; аяллыг дахин үзэх үйлдэл гэдэг нь ойлгомжтой.

Эдгээрээс өөр shader sliders, planet editor, өнгөний laboratory үндсэн туршлагад орохгүй.

## Гар ба touch-ийн нарийн дүрэм

- Input, select, dialog дотор keyboard shortcut санамсаргүй ажиллахгүй.
- Space нь тоглуулах үйлдэл болсон үед хуудсыг гүйлгэхгүй.
- Mouse offset-ийг кадрын захаар хязгаарлана; text/button дээр удирдах үед steer намсана.
- Touch steer зөвхөн сансрын цонхны interaction бүсэд байна; доод товчнуудтай зөрчилдөхгүй.
- Tap ба drag-ийг ялгана; swipe хийсний дараа товч санамсаргүй идэвхжихгүй.
- Pointer/touch алдагдахад steering зөөлөн төвдөө орно; хурдасгал баригдсан төлөвт үлдэхгүй.
- Fullscreen-ээс Esc-ээр гарахад аялал өөрөө дахин эхлэхгүй.

## Хэмжээ ба уншигдах байдал

- Гол touch target хамгийн багадаа 44×44 CSS px.
- Бичвэр ба товч clip хийгдэхгүй; 320 px өргөнд хэвтээ scroll үүсэхгүй.
- Өнгө дангаараа утга дамжуулахгүй.
- Timer/progress-ийг screen reader-д кадр бүр уншуулахгүй. Зөвхөн бүлэг солигдох, pause, error зэрэг утгатай өөрчлөлтийг мэдээлнэ.
- Текстийг 200% томруулсан үед зайлшгүй удирдлагууд ашиглах боломжтой байна.

## Алдаа ба тусгай нөхцөл

| Нөхцөл | Үзэгч юу харах вэ? |
|---|---|
| WebGL 2 байхгүй | Ижил аяллын CSS хөнгөн дүрслэл; нэг удаагийн богино мэдэгдэл |
| Дуу зөвшөөрөгдөөгүй | Дуугүй үргэлжилнэ; асаах товч боломжтой |
| Fullscreen дэмжихгүй | Browser хэмжээгээр хэвийн үргэлжилнэ |
| Tab нуусан | Аялал pause; буцаж ирэхэд resume товч |
| Texture эвдэрсэн | Procedural суурь өнгө, CSS хувилбар; хар дэлгэцгүй |
| WebGL context алдагдсан | Clock pause; CSS төлөв сэргээх; үргэлжлүүлэх санал |
| JavaScript унтраалттай | CSS нээлтийн кадр, бүрэн аялалд JS шаардлагатайг хэлсэн заавар |
| file://-ээр нээсэн | Локал HTTP-ээр нээх ойлгомжтой заавар; бүрэн 3D амлахгүй |

## Аяллыг таслахгүй байх шалгуур

Автоматаар modal нээхгүй. Шинэ tab руу өөрөө шилжихгүй. Технологийн mode үзүүлэхгүй. Feature тайлбар, сурталчилгаа, «дараагийн demo» товч гаргахгүй. Төгсгөл хүртэл хөлөг, өнгө, хөдөлгүүрийн дуу, аяллын цаг нэг бүтээлийнх байна.
