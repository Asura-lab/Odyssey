Энэ файл нь ирээдүйн demo-г юугаар хүлээн авахыг тодорхойлно. Одоогоор доорх шалгалтуудыг гүйцэтгэсэн гэж үзэхгүй. Баримт бичгийн бүрэн байдал болон бодит вебийн QA хоёр тусдаа.

## Гүйцэтгэлийн зорилтот төсөв

Эдгээр нь эхний зорилт; техникийн туршилтын дараа бодит төхөөрөмжийн үр дүнтэй уялдуулна. «Бүх төхөөрөмжид 60 FPS» гэж амлахгүй.

| Үзүүлэлт | Үндсэн чанар | Хөнгөн чанар |
|---|---|---|
| Дэлгэцийн жишиг | 1920×1080 laptop/projector | 1280×720 integrated GPU / утас |
| Frame rate | Тогтвортой 50–60 FPS зорилт | Тогтвортой 30 FPS зорилт |
| Pixel ratio дээд | 1.5 | 1.0 |
| Ойрын 3D одод | 2,000 хүртэл Points | 500 хүртэл |
| CSS одод | 120 хүртэл | 40 хүртэл |
| Warp зурвас | 72 хүртэл | 24 хүртэл |
| Нэг кадрын asteroid | 80 хүртэл instanced | 25 хүртэл |
| Ойрын ring ширхэг | 500 хүртэл | 100 хүртэл эсвэл унтраах |
| Энцеладын plume | 800 хүртэл particle | 150 хүртэл эсвэл хөнгөн туузан дүрслэл |
| Нарны prominence | 6 хүртэл нуман объект | 2 хүртэл, bloom намсгах |
| Planet sphere | 64×32 segment орчим | 32×16 segment орчим |
| Draw call | 60-аас бага зорилт | 30-аас бага зорилт |
| Багцын хэмжээ | 20 MB-аас бага зорилт | Ижил багцын жижиг texture/geometry сонгоно |
| Ашиглаж болох UI | Эхний 2 секундэд HTML shell | Ижил |
| Эхлэхэд бэлэн болох | Локал SSD дээр 5 секундээс бага зорилт | GPU шалгалтын хугацааг хамт хэмжинэ |

Texture-ийн GPU санах ой нь диск дээрх шахсан файлын хэмжээтэй тэнцэхгүй. Том texture-ийг олон хувилбараар зэрэг барихгүй. Зөвхөн одоогийн болон дараагийн scene-ийн идэвхтэй материал үлдээх эсэхийг хэмжилтээр шийднэ.

## Чанарыг автоматаар бууруулах

1. Эхлээд WebGL 2 capability шалгана.
2. Ажиллаж байвал 8–10 секундийн тогтвортой хэсэгт FPS/frame time хэмжинэ; loading болон tab visibility-г хэмжилтэд оруулахгүй.
3. 28 FPS-ээс доош байдал 5 секундээс удаан үргэлжилбэл pixel ratio, particle count, үнэтэй atmosphere effect-ийг бууруулна.
4. Сайжрахгүй бол ижил аяллын CSS хөнгөн дүрслэлд шилжих санал эсвэл автомат шилжилт хийнэ; нэг удаагийн тайван мэдэгдэл өгнө.
5. Чанарыг кадр бүр өөрчилж савлуулахгүй. Хэрэглэгчийн хөнгөн сонголтыг өөрөө хүчингүй болгохгүй.

Автомат чанар бууруулах нь аяллын зохиолыг алгасах, хөлгийг солих, шинэ хуудас нээх шалтгаан биш.

## Reduced motion шаардлага

Системийн `prefers-reduced-motion`-ийг анхнаасаа уншина. Энэ media query нь хэрэглэгчийн чухал биш хөдөлгөөнийг багасгах хүсэлтийг илэрхийлдэг. [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)

| Эффект | Хэвийн | Reduced motion |
|---|---|---|
| Camera bank | Жижиг налалт | 0° |
| Mouse parallax | Хязгаарлагдмал offset | Унтраалттай |
| Warp | Урт зурвас, хурдасгал | Бараг хөдөлгөөнгүй гэрлийн зөөлөн уусалт |
| Flyby | Камерын зам | 2–3 гол композици хооронд удаан уусалт |
| Asteroid | Ойр өнгөрөлт | Алсын удаан/тогтуун дүрслэл |
| Thruster / glow | Зөөлөн pulse | Тогтмол гэрэл |
| Text transition | Богино fade/slide | Fade эсвэл шууд солих |
| Аяллын зохиол | Бүтэн | Бүтэн |

Хөдөлгөөн багасгах нь зөвхөн CSS animation хугацааг бараг тэглэхээр дуусахгүй; JavaScript camera, shader phase, particle хөдөлгөөнд мөн үйлчилнэ. Дууг автоматаар асаахгүй.

## Турших орчны матриц

| Орчин | Хэмжээ/төхөөрөмж | Гол шалгалт |
|---|---|---|
| Windows Chrome | 1920×1080 | Бүтэн аялал, keyboard, audio, fullscreen |
| Windows Edge | 1366×768 | Layout, module, WebGL |
| Firefox | 1440×900 | CSS, shader, audio policy |
| Проектор | 1280×720 эсвэл бодит native хэмжээ | Contrast, жижиг бичвэр, сонсгол |
| Android Chrome | Бодит утас, босоо/хэвтээ | Touch, heat/performance, safe-area |
| iOS Safari | Боломжтой бодит төхөөрөмж | Audio unlock, fullscreen хязгаар, orientation |
| CSS fallback | WebGL хаасан browser | Ижил зохиол, удирдлага, хар дэлгэцгүй |
| Reduced motion | Системд reduce | Бүх scene-ийн camera/CSS |
| JS disabled | Browser context | Нээлтийн кадр ба ойлгомжтой заавар |

Төхөөрөмж байхгүй орчныг «шалгасан» гэж тэмдэглэхгүй. Emulation-аар layout шалгаж болох ч бодит GPU, Safari audio, дулааны гүйцэтгэлийг бүрэн батлахгүй.

## Төлөв ба оролтын тестүүд

- Pause дарахад elapsed хугацаа өсөхгүй.
- Resume яг өмнөх мөчөөс; warp эсвэл audio cue дахин буруу trigger болохгүй.
- Chapter seek нь camera, текст, CSS phase, audio state-ийг нэг мөчид тавина.
- Эхний бүлэгт previous, сүүлд next нь хязгаараа дагана.
- Дууссан үед нэг даралтаар restart; давхар timer үүсэхгүй.
- Dialog нээхэд pause, хаахад өмнөх play/pause төлөвөө сэргээнэ.
- Tab visibility өөрчлөгдөхөд аялал үсэрч урагшлахгүй.
- W/steer дараастай байхад pointer/keyboard focus алдагдвал баригдсан төлөв үлдэхгүй.
- Mute/unmute олон давтахад аудио чангарч давхардахгүй.
- Системийн reduced motion тохиргоо аяллын дунд өөрчлөгдвөл аюулгүй хэрэглэнэ.

## Харагдах байдлын гар шалгалт

Санчирын арын цагираг гаригийг нэвт харагдахгүй. Камер sphere-ийн дотор орохгүй. Бичвэр гаригийн хамгийн тод хэсэгт уусахгүй. Шилний reflection scene-ийг бүрхэхгүй. Flyby-ийн чиглэл солигдох бүрд хөлөг өөрчлөгдсөн мэт харагдахгүй. Нарны flyby-д гадаргуугийн дотор орохгүй, glare бичвэрийг арилгахгүй. Энцеладын plume хар сансарт харагдаж, хөлөгтэй зөв далдлагдана. Voyager танигдах силуэттэй. Төгсгөлийн жижиг Нар эхний том Нартай холбоо үүсгэнэ; Дэлхий рүү буцах кадраар V1-ийг солихгүй.

## QA тайлангийн хэлбэр

Хэрэгжүүлэлтийн дараах тайланд build/version, огноо, төхөөрөмж/browser, туршсан үйлдэл, бодит үр дүн, screenshot, үлдсэн асуудлыг бичнэ. «Бүгд ажиллана» гэх ерөнхий өгүүлбэр хангалтгүй. Одоогийн баримтын багц энэ ирээдүйн тайланг орлохгүй.
