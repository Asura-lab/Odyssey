# 09. Үзүүлэнг богинохон харуулах заавар

## Зориулалт

Энэ бол сонирхол төрүүлэх сансрын аяллын үзүүлэн. Хичээлийн модуль, код заах материал, дагаж хийх төсөл биш. Сурагчдад эх код өгөхгүй; код задлан үзүүлэх, технологийн жагсаалт цээжлүүлэх, дасгал эсвэл даалгавар өгөх шаардлагагүй.

Гол үр дүн: «HTML + CSS дээр тулгуурлаад ийм гоё зүйл хийж болдог юм байна» гэсэн сэтгэгдэл. Үүнийг нэг богино үзүүлэлтээр төрүүлээд өнгөрч болно.

## Үзүүлэхээс өмнө

- Бэлтгэсэн demo тухайн компьютер, дэлгэц дээр нээгдэж байгааг шалгана.
- Интернетгүй үзүүлэх бол локал багц болон нээх арга бэлэн байна.
- Дуу асаах эсэхээ нөхцөлдөө тохируулна; дуугүй ч ойлгомжтой байна.
- Хөдөлгөөн багасгах шаардлагатай бол тайван горим сонгоно.

## Хэр богино үзүүлж болох вэ?

| Хувилбар | Үзүүлэх зүйл | Тайлбар |
|---|---|---|
| Нэг кадр, 15–30 секунд | Нарны flyby, Санчирын цагираг эсвэл Энцеладын оргилуур | Гайхалтай харагдах орчныг шууд харуулах |
| Богино хэсэг, 30–60 секунд | Дэлхийн sunrise, Нар эсвэл Санчир–Энцеладын сонгосон хэсэг | Нэг хөлөг, хөдөлгөөн, гэрэл, орон зайн мэдрэмж |
| V1 бүтэн аялал, 5:40 | Дэлхийн sunrise-аас Нар, гаригуудыг дайраад Voyager хүрэх | Зөвхөн цаг, сонирхол байвал; заавал биш |

Үзүүлэх хугацаанууд нь сонголт. Нэмэлт тусгай highlight видео эсвэл тусдаа demo бүтээх шаардлага биш; ижил аяллын бүлэг сонголт, pause удирдлагыг ашиглана.

## Хэлж болох ганц өгүүлбэр

«HTML + CSS дээр тулгуурлаад, шаардлагатай нэмэлт хэрэгслүүдийг ашиглавал вебээр ийм орчин бүтээж болдог.»

Хүсвэл үүгээр дуусгана. Дараа нь тайлбар, хэлэлцүүлэг, эх кодын walkthrough заавал хийхгүй. Нэмэлт технологи ашигласныг нуух эсвэл «нэг ч JavaScript ашиглаагүй» гэж хэлэхгүй.

## Үзэгчийн дэлгэцэд байх зүйл

Зөвхөн нэг хөлгийн гайхалтай сансрын аялал, хэрэгтэй удирдлага, хүсвэл нээх богино ажиглалт. Код харах товч, CSS лаборатори, сурагчийн дасгал, технологийн тусдаа demo байхгүй.

## Эхний хувилбар гэдгийг яаж ойлгуулах вэ?

V1 нь нарны аймгийн бүрэн үзүүлэн. Ойрын од, аварга улаан од, мананцар, хар нүх дараагийн хувилбаруудад нэмэгдэнэ. Үзүүлэх үед ирээдүйн үзэгдэл ажиллаж байгаа мэт хэлэхгүй; код эсвэл roadmap танилцуулах шаардлагагүй.

## Баримтын хэрэглээ

Технологи, архитектур, материал, чанарын дэлгэрэнгүй баримтууд нь төслийг зөв бүтээх дотоод лавлах юм. Тэдгээрийг сурагчдад тараах шаардлагагүй. Одоогийн үе шатанд зөвхөн эдгээр баримтыг засаж байна; demo хэрэгжүүлэх ажил эхлэхгүй.
