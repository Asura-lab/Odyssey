# ОДИССЕЙ / Odyssey

HTML + CSS дээр тулгуурласан, нэг сансрын хөлгийн кино мэт аяллын веб үзүүлэн.

**Одоогийн төлөв:** төслийн баримт бичиг болон репозиторийн эхний бүтэц бэлэн. Ажиллах demo-ийн хэрэгжүүлэлт хараахан эхлээгүй.

## Эхний хувилбар — нарны аймаг

Дэлхийн нар мандах эхлэл → Нарны flyby → гадагш хурдасгал → астероидын бүс → Бархасбадийн шуурга → Санчирын цагираг → Энцеладын мөсөн оргилуур → Voyager, алсын Нар.

Нэг хөлөг, нэг cockpit, тасралтгүй аялал. Бүтэн найруулгын санал 5:40; сонгосон мөчийг богинохон үзүүлж болно. Сурагчдад код тараах, задалж заах, даалгавар өгөх шаардлагагүй.

## Технологийн зарчим

HTML + CSS нь үндсэн бүтэц, зохиомж, cockpit, гэрэл болон харагдах эффектүүдийн утгатай хэсгийг бүтээнэ. JavaScript, 3D engine, animation library, model, texture, аудио болон шаардлагатай бусад хэрэгслийг нэмэлтээр ашиглаж болно. Технологийн хаалттай жагсаалт тогтоогоогүй; бүх бүтээлийг JS/React эсвэл нэг canvas-д төвлөрүүлэхгүй.

## Төслийн бүтэц

```text
docs/                төслийн 11 баримт
src/styles/          үндсэн CSS ба эффектүүдийн ирээдүйн байрлал
src/scripts/         нэмэлт үйлдэл, синк, renderer-ийн ирээдүйн байрлал
assets/models/       3D материал
assets/textures/     texture
assets/audio/        аудио
assets/icons/        icon, SVG
vendor/licenses/     нэмэлт сан, материалын лиценз
tests/               хэрэгжүүлэлттэй хамт нэмэх шалгалтууд
```

Хоосон хавтаснуудыг Git-д хадгалах зорилгоор `.gitkeep` ашигласан. Одоогоор dependency суулгах, build хийх, ажиллуулах команд байхгүй. Тэдгээрийг бодит хэрэгжүүлэлттэй хамт нэмж баримтжуулна.

## Дараагийн ажил

V1-ийн HTML/CSS cockpit ба үндсэн хөдөлгөөний суурийг бэлтгэж, шаардлагатай нэмэлт дүрслэлийн хэрэгслийг сонгоно. Хөгжүүлэлтийн үе шатуудыг [roadmap](docs/07_Хөгжүүлэлтийн_roadmap.md)-аас харна уу.
